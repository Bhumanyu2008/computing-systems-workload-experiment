# Computing Systems Workload Experiment

This Python script compares the execution time of Bubble Sort and Python's built-in `sorted()` function across four list sizes (500, 2000, 5000, and 8000), averaged over 3 trials.

## How to Reproduce
1. Make sure Python 3 is installed on your computer.
2. Download `workload_experiment.py`.
3. Open Terminal in the folder containing the file and run:
   ```bash
   python3 workload_experiment.py

4. Click the green **Commit changes...** button at the top right, then click **Commit changes** in the pop-up box to save it.

Once saved, that text will automatically appear neatly formatted on your repository's main page.
